# MewSim

Адаптированная для Android 16 сборка старой игры MewSim.

Готовый установочный файл находится в [release/MewSim-1.4.0-Android16.apk](release/MewSim-1.4.0-Android16.apk). Он протестирован на Samsung Galaxy S24 Ultra с Android 16: установка, запуск, управление и сохранение прогресса после перезапуска работают.

## Что находится в репозитории

- `decoded/` — декомпилированная рабочая структура Android-приложения: Java/Smali, ресурсы и данные игры.
- `dpmod_arm64.cpp` — восстановленный 64-битный модуль, необходимый для запуска на современных устройствах ARM64.
- `sign-apk.ps1` — локальный сценарий выравнивания и подписи APK.
- `tools/apktool.jar` — средство для упаковки декомпилированного проекта.
- `release/` — готовый APK, контрольная сумма и результаты проверки.

## Изменения совместимости

- Целевой уровень Android повышен до API 24, чтобы приложение устанавливалось на Android 16.
- Сохранена распаковка нативных библиотек, которую требует старый игровой движок.
- Путь к общей памяти заменён на доступную приложению папку.
- Добавлен ARM64-вариант служебного модуля, отсутствовавший в исходном APK.

## Сборка

Нужны Java 17+, Android SDK Build Tools и собственный ключ подписи. Распакуйте проект и выполните:

```powershell
java -jar tools/apktool.jar b decoded -o MewSim-unsigned.apk
```

Затем подпишите APK своим ключом. Для локальной автоматизации можно использовать `sign-apk.ps1`, предварительно поместив ключ и пароль в папку `signing/`; эта папка намеренно не публикуется.

Игра, её графика, аудио и торговые материалы принадлежат их правообладателям. Репозиторий предназначен для сохранения и личной совместимой сборки приложения.
